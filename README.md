# AIChatFlutter

Мобильное приложение на Flutter для чата через OpenRouter и VSEGPT с входом по четырёхзначному PIN.

## Возможности

- Определение провайдера по API-ключу: OpenRouter — `sk-or-v1-`, VSEGPT — `sk-or-vv-` и `sk-or-vis-`.
- Проверка ключа и положительного баланса при первом входе.
- Автоматическая генерация PIN; сохранение ключа и хэша PIN с солью в SQLite.
- Повторный вход по PIN, сообщение о неверном PIN и сброс ключа.
- Загрузка моделей и отправка сообщений через выбранного провайдера.
- Сохранение истории, экспорт диалогов и аналитика.

## Запуск на Android

Требуются Flutter 3.50.0, Android SDK, Android NDK 28.2.13676358 и подключённый телефон или запущенный эмулятор. Путь к проекту в Windows должен содержать только латинские символы.

```powershell
flutter pub get
flutter devices
flutter run -d ID_УСТРОЙСТВА
```

Замените `ID_УСТРОЙСТВА` на идентификатор Android-устройства из `flutter devices`.

Файл `.env` не требуется: ключ вводится в приложении. Для VSEGPT в личном кабинете должно быть включено «Разрешить запрашивать баланс по API». Запросы генерации оплачиваются по тарифам провайдера.

## Проверка

```powershell
flutter analyze
flutter test
```

Ручная проверка: ввести ключ с положительным балансом, запомнить показанный PIN, перезапустить приложение, проверить неверный и правильный PIN, затем сбросить ключ и ввести новый.

## Хранение данных

SQLite `chat_cache.db`: история в таблице `messages`, данные авторизации в `auth`. Сброс ключа сохраняет историю. PIN хранится как хэш с солью; API-ключ хранится локально без шифрования.

Исходный проект: [neuro-fill/AIChatFlutter](https://github.com/neuro-fill/AIChatFlutter).
