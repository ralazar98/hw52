# AIChatFlutter: аутентификация OpenRouter и VSEGPT

Flutter-приложение чата с авторизацией по API-ключу и повторным входом по четырёхзначному PIN.

**Начните с [START_HERE.md](START_HERE.md)** — там установка, запуск на Android и пошаговая проверка задания.

## Что реализовано

- Определение OpenRouter по `sk-or-v1-`, VSEGPT по `sk-or-vv-` и дополнительно `sk-or-vis-`.
- Проверка действительности ключа и положительного баланса до создания учётных данных.
- Криптографически случайный PIN, показ пользователю и сохранение проверочного хэша с солью в SQLite.
- Повторный вход по PIN, ошибка неверного PIN и сброс ключа.
- API-адрес, модели и валюта баланса соответствуют сохранённому провайдеру.
- Миграция SQLite без удаления истории сообщений.
- Сохранены история, экспорт, очистка и аналитика чата.

## Команды

```powershell
flutter pub get

```

Целевая среда: Android, Flutter 3.50.0. Для запуска файл `.env` не требуется. Веб-версия не реализована.

## Хранение данных

Файл `chat_cache.db`, версия схемы 2. Таблица `messages` сохраняет историю, таблица `auth` — API-ключ, провайдера и хэш PIN с отдельной солью. Сброс ключа очищает только `auth`.

PIN хранится как проверочный хэш, а не как исходные цифры. Это учебная локальная блокировка: сам API-ключ хранится в SQLite без шифрования, защита от извлечения базы и перебора PIN не реализована.

## Происхождение изменений

Исходная версия: https://github.com/neuro-fill/AIChatFlutter

За основу взят предоставленный пользователем архив после работы Cline. Его модель `AuthData` и схема `auth` сохранены и завершены. Последующая доработка и тестирование выполнены напрямую, а не через Cline. Подробности — [CHANGES.md](CHANGES.md).
