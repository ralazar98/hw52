# Как запустить исправленный AIChatFlutter

Этот проект продолжает вашу версию после работы Cline. Используйте эту папку целиком: не копируйте её поверх старой версии, чтобы старые Gradle-файлы не смешались с новыми.

## 1. Распаковка и открытие

1. Распакуйте архив в отдельную папку, например `C:\projects\AIChatFlutter-ready`.
2. В VS Code откройте папку, где находится `pubspec.yaml`.
3. Если терминал VS Code не находит Flutter, полностью закройте VS Code и откройте снова или используйте PowerShell, в котором работает `flutter doctor`.
4. В PowerShell перейдите в свою распакованную папку:

```powershell
Set-Location "C:\projects\AIChatFlutter-ready"
flutter pub get
flutter analyze
flutter test
```

Проект проверен на Flutter 3.50.0 / Dart 3.14.0. Android-файлы сборки обновлены по шаблону этой версии Flutter. Для Android нужны Android Studio, SDK и подходящий JDK (рекомендуется встроенный в Android Studio JDK 21).

Файл `.env` создавать не нужно. Реальный ключ вводится только на экране приложения.

## 2. Устройство и запуск

Запустите Android-эмулятор через Android Studio → Device Manager или подключите Android-телефон с включённой отладкой по USB.

```powershell
flutter devices
flutter run -d ID_УСТРОЙСТВА
```

Вместо `ID_УСТРОЙСТВА` подставьте идентификатор Android-устройства из `flutter devices`. Не выбирайте Chrome: эта версия использует нативную SQLite и предназначена для Android, а не для браузера.

При первом запуске Gradle может загрузить инструменты сборки и недостающую платформу Android. Это отдельная загрузка, не использующая баланс VSEGPT.

## 3. Проверка задания

1. Введите ключ OpenRouter (`sk-or-v1-…`) или VSEGPT (`sk-or-vv-…`). Поддерживается также ваш текущий префикс VSEGPT `sk-or-vis-…`.
2. При положительном балансе приложение создаст PIN и покажет его. Запишите PIN, затем нажмите «Я запомнил PIN — открыть чат».
3. Выберите модель и отправьте короткое сообщение. Реальная генерация оплачивается у выбранного провайдера; автотесты платных запросов не выполняют.
4. Полностью закройте процесс приложения и откройте снова: должен появиться ввод PIN. Неверный PIN вызывает ошибку, правильный открывает чат.
5. Для быстрой проверки без перезапуска откройте меню ⋮ → «Заблокировать / сменить ключ».
6. На экране PIN нажмите «Сбросить ключ». Откроется ввод нового ключа. Можно сменить провайдера; история сообщений сохраняется.
7. Неверный ключ, баланс 0 или отсутствие сети не должны создавать PIN или открывать чат.

VSEGPT: в кабинете должна быть включена галочка «Разрешить запрашивать баланс по API». Если она выключена, приложение покажет подсказку. При повторном входе по PIN запрос баланса для допуска в чат не нужен; загрузка моделей и отправка сообщений требуют сети.

## Проверено и что осталось проверить

- `flutter pub get --offline`: успешно на подготовленном кэше зависимостей.
- `flutter analyze --no-pub`: **No issues found!**
- `flutter test --no-pub`: **42 теста прошли**.
- Проверены запросы обоих провайдеров на подставных HTTP-ответах, ошибки и тайм-ауты, положительный/нулевой/отрицательный баланс, полный экранный сценарий входа, смена провайдера, реальные SQLite-операции и миграции с версий 1 и 2.
- Попытка `flutter build apk --debug --no-pub` остановилась: в среде проверки не установлен полноценный Android SDK. APK не собран и запуск на Android не подтверждён. Проверку на вашем устройстве нужно выполнить командами выше.
- Ваши реальные API-ключи не использовались. В архиве нет сохранённой базы пользователя, `.env`, локальных путей SDK или кэшей сборки.

Подробности изменений — в `CHANGES.md`, вывод проверок — в папке `verification`.
