# Установка и запуск

Актуальная инструкция для этой версии находится в [START_HERE.md](START_HERE.md).

Используйте Flutter 3.50.0 и Android SDK. Перед запуском выполните `flutter doctor`.

```powershell
flutter pub get
flutter analyze
flutter test
flutter devices
flutter run -d ID_УСТРОЙСТВА
```

Ключ вводится в приложении; создавать `.env` и вставлять ключ в исходники не требуется.
