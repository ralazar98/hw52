# Что изменено относительно вашего архива

## Продолжена работа Cline

В архиве после Cline уже были `lib/models/auth_data.dart`, версия БД 2 и таблица `auth`. Экран входа, сохранение/чтение авторизации и подключение ключа к чату отсутствовали. В этой версии модель и схема завершены; предоставленная структура истории сохранена.

## Изменения

| Файл | Назначение |
|---|---|
| `lib/models/auth_data.dart` | Добавлено поле соли в модель и сериализацию, строгая проверка префиксов, `sk-or-vis-`, генерация и проверка хэша PIN |
| `lib/services/database_service.dart` | Чтение/атомарная замена/сброс авторизации, одно открытие БД при параллельных запросах, сохранение существующей миграции |
| `lib/services/balance_service.dart` | Проверка баланса двух провайдеров, сетевые ошибки и тайм-ауты, проверка полей ответа, подсказка о настройке баланса VSEGPT |
| `lib/services/auth_service.dart` | Регистрация только при балансе > 0, случайный PIN, сохранение хэша с солью, вход и сброс |
| `lib/screens/auth_screen.dart` | Ввод ключа, ожидание проверки, показ PIN, повторный вход, ошибки и сброс |
| `lib/screens/auth_gate.dart` | Создание чата только после входа, выбор ключа сессии |
| `lib/main.dart` | Удалена обязательная загрузка `.env`, подключён AuthGate, сохранены тема и локализация |
| `lib/api/openrouter_client.dart` | Ключ передаётся из сессии вместо Singleton/.env; правильные endpoints; нормализация моделей и цен, UTF-8, безопасные сообщения ошибок |
| `lib/providers/chat_provider.dart` | Клиент сессии, обработка ответов без usage и строковой стоимости, повторная загрузка моделей, корректное освобождение клиента |
| `lib/screens/chat_screen.dart` | Блокировка/смена ключа из меню, правильная валюта VSEGPT, ограничение ширины баланса, повтор загрузки моделей, стандартный Roboto |
| `pubspec.yaml`, `pubspec.lock` | Убраны dotenv/Google Fonts, совместимый диапазон intl; фиксация зависимостей |
| Android Gradle-файлы | Обновлены по штатному шаблону Flutter 3.50.0; namespace и ресурсы приложения сохранены |
| `test/` | 42 проверки логики, API, экранов, чата и SQLite |

Отдельные исходные Dart-файлы также отформатированы стандартным Dart formatter без изменения их логики.

## Проверки

Flutter 3.50.0, Dart 3.14.0, Linux.

- Анализатор: No issues found.
- 42 теста: All tests passed.
- Тесты обращаются к MockClient и временной SQLite, а не к платным API.
- Для Linux-тестов использовалась установленная системная SQLite. На Linux необходима `libsqlite3`; в Windows sqflite_common_ffi использует свою библиотеку SQLite для debug-тестов.
- Нативная Android-сборка: не выполнена, отсутствует полный Android SDK в среде проверки. Запуск на реальном Android/эмуляторе остаётся ручной проверкой.
- Некоторые исходные Material API помечены deprecated в Flutter 3.50. Сохранены ради совместимости; подавлены только соответствующие точечные уведомления об устаревании. Ошибки и остальные предупреждения анализатора не отключались.
